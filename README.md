# Pilas · Plataforma Web de Emergencias Urbanas

Proyecto universitario. Ver instrucciones de cada fase en este archivo (se completará en la FASE 5).

## Correr el frontend (FASE 1)

```bash
cd frontend
npm install
npm run dev
```

- `frontend/` → React + Vite + MapLibre (datos simulados en `src/data/mockData.js`).
- `legacy/` → la primera versión en HTML/CSS (referencia).
- Cambiar el nombre de la app: `frontend/src/config.js` → `APP_NAME`.
